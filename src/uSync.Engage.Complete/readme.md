# uSync.Engage.Complete

Adds uSync.Complete's push and pull options to Umbraco Engage, so you can send Engage
settings between sites from Engage's own screens:

- persona groups
- customer journeys
- goals
- campaign groups
- segments
- traffic filters

Each item is sent on its own. Anything it refers to (personas, journey steps, goals,
content) needs to be on the other site already, or be pushed first.

Requires uSync.Complete 17, uSync.Engage 17 and Umbraco Engage 17.5 or later.

https://github.com/Jumoo/uSync.Engage
